AveeCare packages

Packages for the AveeCare command line tool. They need Node.js 18 or newer, which the package manager installs from your distribution.

Debian and Ubuntu

Debian 12 or newer, Ubuntu 24.04 or newer.

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://aveecare.github.io/packages/aveecare.asc | sudo tee /etc/apt/keyrings/aveecare.asc >/dev/null
echo "deb [signed-by=/etc/apt/keyrings/aveecare.asc] https://aveecare.github.io/packages/deb ./" | sudo tee /etc/apt/sources.list.d/aveecare.list
sudo apt update && sudo apt install aveecare-cli

Fedora, RHEL and compatible

On RHEL 9 and compatible, first run sudo dnf module enable nodejs:20.

sudo curl -fsSL -o /etc/yum.repos.d/aveecare.repo https://aveecare.github.io/packages/aveecare.repo
sudo dnf install aveecare-cli

openSUSE

sudo zypper addrepo https://aveecare.github.io/packages/aveecare.repo
sudo zypper install aveecare-cli
